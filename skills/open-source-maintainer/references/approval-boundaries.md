# 操作审批边界

| 操作 | 默认处理 |
| --- | --- |
| 搜索、阅读、分析 | 自动执行 |
| 编辑、格式化、测试和本地构建 | 可信工作区自动执行，不可信贡献使用隔离环境 |
| 本地提交 | 自动执行，但只暂存任务文件并扫描敏感信息 |
| 普通远端推送 | 执行前确认目标仓库、分支、提交 SHA 和 CI 副作用 |
| 强推、删除分支或标签 | 必须确认 |
| Issue/PR 评论、关闭或合并 | 必须确认 |
| 发布包、镜像或正式标签 | 必须确认并完成发布清单 |
| 清理未跟踪文件或硬重置 | 必须确认并先展示将丢失的内容 |
| 凭据提交或外传 | 禁止。进入泄漏处理流程 |

## 提交前检查

1. 记录任务开始时的工作树和暂存区。
2. 只暂存任务明确涉及的文件。
3. 检查 git diff --cached 和文件列表。
4. 扫描密钥、Token、私钥、环境文件和已跟踪敏感文件。
5. 确认提交不包含其他任务的改动。
